## ▶️ How to Run

1. Open any `.ipynb` file from a practical folder in **Google Colab** or **Jupyter Notebook**.
2. Upload the dataset CSV used in that practical and update the file path in the `pd.read_csv()` cell.
3. Run all cells from top to bottom.
